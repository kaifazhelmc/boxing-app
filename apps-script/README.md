# 拳擊跟練：Google 雲端硬碟備份設定教學

只要設定一次，大約 5 分鐘。備份檔會存在**你自己的** Google 雲端硬碟，別人看不到。

## 1. 建立 Apps Script

1. 用電腦打開 <https://script.google.com>，登入你的 Google 帳號
2. 左上角按「**新專案**」
3. 把編輯器裡原本的內容全部刪掉，貼上 [`Code.gs`](Code.gs) 的全部內容
4. 找到第 10 行：
   ```js
   const SECRET = '請改成你自己的密碼';
   ```
   把引號裡的字改成你自己想的密碼（英文數字就好，例如 `boxing2026abc`），記下來
5. 左上角把專案名稱改成「拳擊跟練備份」，按 💾 儲存

## 2. 部署成網頁應用程式

1. 右上角按「**部署**」→「**新增部署作業**」
2. 左邊齒輪 ⚙️ 選「**網頁應用程式**」
3. 設定：
   - 執行身分：**我**
   - 誰可以存取：**所有人**
4. 按「部署」
5. 第一次會要求授權：按「授權存取」→ 選你的帳號
   - 出現「**Google 尚未驗證這個應用程式**」是正常的，因為這是你自己寫的程式。按左下角「**進階**」→「**前往 拳擊跟練備份（不安全）**」→「**允許**」
6. 複製畫面上的「**網頁應用程式網址**」（`https://script.google.com/macros/s/…/exec`）

## 3. 在 App 裡設定

1. 打開拳擊跟練 → 下方「**紀錄**」→「**Google 雲端備份**」
2. 貼上剛剛的網址，密碼填第 1 步設定的密碼
3. 按「**儲存設定並測試**」，出現「連線成功」就完成了

之後每次打完按「完成」就會自動備份。換手機時，在新手機做第 3 步，然後按「**從雲端還原**」。

## 備份存在哪裡

Google 雲端硬碟 →「拳擊跟練備份」資料夾：
- `最新備份.json`：最新的資料
- `快照-日期.json`：每天一份，保留 30 天，萬一資料出問題可以找回之前的版本

## 常見問題

- **「誰可以存取：所有人」安全嗎？** 網址加上密碼才能讀寫，密碼不對會被拒絕。不要把網址和密碼一起給別人就好。
- **之後修改了 Code.gs** 要重新部署：部署 →「管理部署作業」→ 編輯 → 版本選「新版本」→ 部署。網址不會變。
